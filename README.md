# Æon irssi theme

A clean, modern irssi theme with consistent color coding and improved readability.

## Installation

```bash
cd ~/.irssi
wget https://raw.githubusercontent.com/yourusername/aeon-irssi-theme/main/aeon.theme
```

Load the theme in irssi:

```
/set theme aeon
```

## Features

- Clean, modern aesthetic with consistent single-color status messages
- Improved join/part/quit visibility with full color highlighting
- Sentence case formatting throughout
- Optimized for readability with clear visual hierarchy
